# 긴장의 시대 — Firebase Realtime Database 온라인 MVP

이 프로젝트는 설치 없이 웹브라우저에서 실행하는 것을 목표로 만든 1차 프로토타입입니다.

## 들어있는 기능

- 방 생성 / 6자리 방 코드 참가
- Firebase Anonymous Authentication
- Firebase Realtime Database 실시간 동기화
- 4개 국가 중 선택
- 방장 게임 시작
- 공개 성명
- 협정 제안
- 경제 원조
- 경제 제재
- 비밀 외교 메시지
- 국경 병력 증강
- 최후통첩
- 전쟁 선포
- 세계 긴장도
- 국가별 군사력 / 경제력 / 영향력 / 신뢰도
- 국제 뉴스/행동 기록
- 방장이 라운드 진행
- 선택적으로 세계 사건 발생

## 국가

### 아우로리아 연방
군사 강국. 높은 군사력 대신 낮은 국제 신뢰도를 가집니다.

### 벨바르 공화국
경제 강국. 무역과 경제 압박에 강합니다.

### 키레네 왕국
자원 강국. 에너지와 해협 접근권을 둘러싼 중심 국가입니다.

### 도란 중립연합
외교 강국. 군사력은 약하지만 높은 신뢰도와 영향력을 가집니다.

## 기본 시나리오: 해협 위기

아르덴 해협에서 무장 충돌이 일어나며 국제적 긴장이 높아진 상태로 시작합니다.
시스템이 정해진 이야기를 강제로 진행하기보다 플레이어의 협상, 거짓말, 동맹, 제재,
군사행동과 전쟁선포가 실제 사건을 만들도록 설계했습니다.

세계 사건 버튼은 보조 장치입니다. 매 턴 자동으로 발생하지 않습니다.

# Firebase 설정

## 1. Firebase 프로젝트 만들기

Firebase Console에서 프로젝트를 생성합니다.

## 2. 웹 앱 추가

프로젝트 설정 > 내 앱 > Web 앱 추가 후 Firebase 설정 객체를 확인합니다.

`firebase-config.js`의 값을 본인의 프로젝트 설정으로 교체합니다.
`databaseURL`이 꼭 포함되어야 합니다.

## 3. Realtime Database 만들기

Build > Realtime Database > Create Database

데이터베이스 위치를 선택하고 생성합니다.

## 4. Anonymous Authentication 켜기

Authentication > Sign-in method > Anonymous 를 활성화합니다.

이 프로젝트는 별도의 회원가입 없이 플레이어마다 임시 UID를 받습니다.

## 5. Database Rules

`database.rules.json` 내용으로 Realtime Database Rules를 설정합니다.

현재 rules 파일은 **학교 프로젝트/테스트용 프로토타입 규칙**입니다.
로그인된 익명 사용자라면 방 데이터를 읽고 쓸 수 있기 때문에 공개 서비스로 출시할 수준의 보안은 아닙니다.

실제 배포 단계에서는:
- 방 참가자만 읽기 허용
- 각 사용자가 자기 플레이어 데이터만 수정
- 방장만 라운드/세계 이벤트 수정
- 서버 검증 또는 Cloud Functions
등을 추가하는 것이 좋습니다.

## 6. 실행

Firebase 브라우저 모듈을 사용하므로 별도 npm 설치는 필요하지 않습니다.

단, `file://`로 HTML 파일을 직접 열기보다 정적 웹호스팅 주소에 올려 실행하는 것이 안정적입니다.

가능한 예:
- GitHub Pages
- Firebase Hosting
- Netlify 등의 정적 호스팅

학교 노트북에서 앱 설치가 제한되어 있다면 GitHub Pages처럼 브라우저에서 업로드/관리할 수 있는 방식을 우선 고려할 수 있습니다.

## 참고

현재 버전은 "완성품"이 아니라 핵심 재미가 실제로 성립하는지 확인하는 MVP입니다.
특히 플레이어끼리 만드는 사건을 중심으로 했기 때문에, 자동 이벤트는 최소한으로만 포함했습니다.
