# 승부수 — 온라인 2인 카드 대전

기존 국제정치 게임과 분리된 브라우저 카드게임 MVP입니다.

## 접속

GitHub Pages 배포가 완료되면 다음 주소에서 실행합니다.

https://y2510223-lab.github.io/international-politics-game/rps-card-duel/

## 시작 방법

1. 위 주소를 두 플레이어가 각각 브라우저에서 엽니다.
2. 각자 플레이어 이름을 입력합니다.
3. 한 명은 **새 대전 방 만들기**를 누릅니다.
4. 방 코드를 친구에게 전달합니다.
5. 다른 플레이어는 방 코드를 입력하고 **참가**를 누릅니다.
6. 방장이 **게임 시작**을 누릅니다.

로그인 계정이나 앱 설치 없이 Firebase 익명 인증으로 접속합니다.

## 구현된 화면과 기능

- 타이틀 / 방 생성 / 방 코드 참가 / 대기실
- 16:9 데스크톱을 우선한 게임 화면과 반응형 레이아웃
- 상단 우측 설정 메뉴와 항복 기능
- 각 플레이어 3열 × 2행 필드, 상대 손패 매수 표시
- 손패 세로형 카드와 필드 가로형 카드
- 공용 덱, 시작 손패 2장, 4장 용병시장
- 공격자 → 상대 → 상대 → 공격자 시장 선택
- 공격자부터 번갈아 한 장씩 배치
- 두 플레이어의 연속 패스 후 공격자 전투 결정
- 60초 행동 제한과 시간 초과 처리
- 전투 중 마법 사용, 세로줄별 전투 판정, 점수 계산
- 12점 승리, 항복, 결과 화면
- 짝수 턴 종료 시 손패 폐기 후 2장씩 드로우

## 턴 종료 및 손패 UI

- 내 배치 차례에는 손패 영역에 **턴 종료** 버튼이 표시됩니다.
- 이 버튼은 현재 플레이어의 배치 차례를 패스합니다. 상대도 연속으로 패스해야 공격자의 전투 결정 단계로 넘어갑니다.
- 손패 카드는 겹치는 부채꼴 형태를 유지하며, 가운데 카드가 앞 레이어에 오고 바깥쪽 카드가 뒤 레이어에 놓입니다.

온라인 대전과 독립된 카드 배치·전투 테스트 페이지:
https://y2510223-lab.github.io/international-politics-game/rps-card-duel-lab/

실험실은 Firebase나 온라인 방에 연결되지 않으며, 로컬에서 카드 조합과 전투 이벤트를 시험합니다.

## 최근 UI 및 전투 연출 업데이트

- 지도와 양피지 느낌의 세피아 배경
- 상단 HUD에 턴 번호, 공격자, 현재 행동자, 60초 타이머 표시
- 플레이어별 3열 × 2행 필드와 우측 용병시장 영입 기록
- 영입 기록에 턴, 선택한 플레이어, 선택 순서, 카드 종류 저장
- 손패 카드를 세로형 트럼프 카드 비율로 표현하고 부채꼴로 회전 배치
- 용병시장은 전체 화면 오버레이로 열리고, 접기 / 다시 열기 가능
- 시장을 접어도 제한 시간은 계속 진행
- 마법 단계가 끝나면 전투를 단계별로 동기화해 재생
  1. 카드 공개
  2. 상성이 유리한 카드의 공격 전진
  3. 패배 카드 파괴
  4. 후열 카드 전진
  5. 다음 카드 재대결 또는 무승부 처리
  6. 줄별 점수 표시
- 애니메이션은 간단한 CSS 이동·흔들림·제거 효과를 사용하며, 화려한 파티클은 아직 추가하지 않음

## 현재 적용한 카드 판정

- 주먹은 가위를 이기고, 가위는 보를 이기며, 보는 주먹을 이깁니다.
- 특수 보는 직접 대결에서 비기면 별도로 1점을 얻습니다.
- 특수 주먹이 살아남아 해당 줄에서 점수를 얻으면 2점을 얻습니다.
- 특수 가위가 살아남아 해당 줄에서 패배하면 상대의 그 줄 점수를 차단합니다.
- 특수 카드가 파괴되면 그 카드의 효과는 즉시 사라집니다.
- 조건부 승리 카드는 상대 줄의 생존 카드가 1장일 때 승리합니다. 조건이 성립하지 않는 대결은 현재 무승부로 처리합니다.

마지막 항목의 조건 미충족 시 처리 방식은 원래 기획 문서에 명시되어 있지 않아 테스트용 임시 판정입니다.

## 용병시장 덱 수량

카드 종류별 4장씩, 총 40장을 사용하는 임시 테스트 덱입니다. 실제 밸런스가 확정된 수량은 아닙니다.

## Firebase

이 게임은 저장소 루트에서 사용 중인 Firebase 프로젝트 설정을 별도 파일 `firebase-config.js`에 복사해 사용합니다.

필요 설정:
- Firebase Authentication의 익명 로그인 활성화
- Realtime Database 생성
- 현재 프로젝트에 설정된 `rooms/$roomId` 인증 사용자용 읽기/쓰기 규칙

게임 데이터는 `/rooms/rps-card-duel/{방코드}` 아래에 저장됩니다. 현재 기존 프로젝트의 Realtime Database 규칙은 로그인된 익명 사용자에게 넓은 읽기/쓰기 권한을 주는 테스트용 규칙입니다. 따라서 이 MVP는 친구와 기능을 시험하는 용도이며, 공개 서비스로 배포하기 전에는 서버 검증과 방 참가자별 접근 제어를 추가해야 합니다.

## 시간 초과

- 시장 선택 시간 초과: 공개된 카드 중 첫 번째 카드를 자동 선택
- 카드 배치 시간 초과: 배치하지 않음(패스)
- 전투 결정 시간 초과: 전투하지 않음
- 마법 사용 시간 초과: 마법을 사용하지 않음(패스)

## 테스트 시 확인할 점

- 두 브라우저 창 또는 두 기기에서 같은 방 코드로 접속
- 양쪽의 카드 배치와 손패 수가 실시간으로 갱신되는지 확인
- 60초 타이머가 양쪽에서 비슷하게 감소하는지 확인
- 전투 선언 / 마법 효과 / 점수 / 항복 결과가 양쪽에 동일하게 표시되는지 확인
- 2번째 턴 종료 때 손패가 버려지고 각자 2장씩 드로우되는지 확인
