# 승부수 실험실

온라인 대전과 분리된 1인용 카드 전투 테스트 공간입니다.

## 실행 주소

https://y2510223-lab.github.io/international-politics-game/rps-card-duel-lab/

## 사용 방법

1. 상단에서 플레이어 A 또는 B를 선택합니다.
2. 오른쪽 카드 목록에서 테스트할 유닛을 선택합니다.
3. 필드의 원하는 빈 슬롯을 클릭해 카드를 배치합니다.
4. 반대쪽 플레이어도 같은 방식으로 카드를 배치합니다.
5. 전투 시뮬레이션을 시작한 뒤 다음 단계 또는 자동 재생을 누릅니다.
6. 전투를 되돌려 카드 배치를 바꾸고 다시 테스트합니다.

배치된 카드는 해당 슬롯을 다시 클릭하면 제거됩니다. 각 플레이어 필드를 따로 비울 수도 있습니다.

## 포함 기능

- 기본 유닛 3종과 특수 유닛 4종의 자유 배치
- 양쪽 플레이어 필드 3열 × 2행 편집
- 전열/후열 전진과 가위바위보 상성 시뮬레이션
- 카드 공격, 파괴, 후열 이동, 무승부 및 점수 이벤트의 단계별 재생
- 한 단계씩 진행, 자동 재생, 중지, 전투 되돌리기
- 전열 교환, 상대 카드 파괴, 긴급 배치 마법의 단독 테스트
- 승리 목표 점수, 줄 점수, 특수 주먹 배율, 특수 보 보너스, 애니메이션 속도 조절
- 실험 메모 입력 및 결과 텍스트 내보내기

## 온라인 게임과의 분리

- Firebase를 불러오지 않습니다.
- 익명 로그인이나 방 코드를 사용하지 않습니다.
- 이 페이지에서 수행한 테스트는 온라인 대전의 상태나 카드에 영향을 주지 않습니다.
- 브라우저 안에서 동작하는 로컬 시뮬레이터입니다.

## 현재 판정 가정

온라인 게임에서 사용하는 카드 판정 로직을 바탕으로 작성했지만, 실험실의 점수 설정은 테스트 편의를 위해 조정할 수 있습니다. 조건부 승리 카드의 조건이 성립하지 않을 때는 현재 무승부로 처리합니다.
