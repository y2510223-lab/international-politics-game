# 긴장의 시대 — 4인 국제정치 멀티플레이 v4

첨부된 「4인 국제 정치 이론 게임 기획안」에 맞춘 새 구현입니다. 기존 국가 이름을 이어 쓰고, 4명이 동시에 10턴 동안 국가를 운영합니다.

## 플레이

1. 지도자 이름을 입력하고 방을 만듭니다.
2. 6자리 코드 또는 초대 링크를 다른 3명에게 전달합니다.
3. 각자 서로 다른 국가를 선택하고 준비 완료를 누릅니다.
4. 방장이 시작하면 정책 선택 → 국가 행동 → 외교 응답을 동시에 진행합니다.
5. 10턴이 지나면 번영·민심·안보·외교·국가 목표 점수를 표시합니다.

기본 턴 시간은 90초입니다. 방장이 대기실에서 60/90/120초로 변경할 수 있습니다. 한 브라우저 프로필은 한 플레이어입니다. 실제 4대의 기기 또는 서로 다른 브라우저 프로필로 접속하세요. 새로고침·재접속은 7일짜리 HttpOnly 세션 쿠키로 복구합니다. 게임은 접속이 끊겨도 논리적으로 진행되며 다음 요청에서 경과 시간을 정산합니다.

## 국가와 이론

| 국가 | 학습용 성향 | 국민 요구 / 국가 목표 능력치 |
|---|---|---|
| 아우로리아 연방 | 현실주의 | 군사력 65 이상 / 군사 |
| 벨바르 공화국 | 자유주의 | 경제 70 이상 / 경제 |
| 키레네 왕국 | 종속이론 | 인프라 60 이상 / 인프라 |
| 도란 중립연합 | 구성주의 | 국제 관계 70 이상 / 관계 |

이론은 학습용으로 단순화했으며 선택 가능한 행동을 강제하지 않습니다. 종속이론은 국제 경제의 구조적 불평등에 초점을 맞춘 설정입니다. 국가별 정책 선택지 3개는 매 턴 같은 정책 기조를 제공하며, 무작위 세계 사건과 국가 상황이 달라져 정책의 가치가 변합니다.

## 기능

- 서버가 판정하는 최대 4인 방, 중복 국가 선택 방지, 준비/시작/대기실 나가기와 방장 이전
- 1.5초 간격 상태 동기화, 서버 기준 동시 턴과 지속 수입
- 국가별 능력치·시작 국고·국민 요구·배경 그림 및 위치 지도
- 턴 시작 정책 선택과 큰 이득/손실, 미선택 시 지지 −6
- 공개 성명, 협정 제안/수락/거절, 원조, 제재
- 당사자만 열람하는 비밀 전문과 비공개 협력
- 병력 증강, 최후통첩/양보/거부, 군사력 기반 전쟁 판정과 피해
- 경제·민생·인프라 투자, 최대 4개의 동시 진행 행동
- 무작위 세계 사건 7종과 국가별 지역 효과, 범주별 행동 비용 변동
- 2턴마다 최근 공개 사건·행동과 국민 요구를 종합하는 규칙 기반 뉴스, 지지율 변화
- 10턴 후 5개 분야 평가와 종합 점수, 동점 공동 순위
- 반응형 한국어 UI와 선택 기능을 지원하는 키보드 접근성, 감소된 동작 설정

## 기술 구조

- React / Vinext 기반 UI, Cloudflare Worker API, D1 SQLite 영속 저장
- `lib/game.ts`: 서버 판정용 규칙, 시간 정산, 결과·뉴스 생성 및 비공개 정보 필터
- `app/api/game/route.ts`: 세션 쿠키, 입력 검증, 같은 출처 확인, 방 데이터 읽기/쓰기
- `db/schema.ts`, `drizzle/`: 스키마와 마이그레이션
- `app/page.tsx`, `app/globals.css`: 대기실, 운영 화면, 최종 평가
- D1에 방 상태와 revision을 저장하고 조건부 UPDATE로 동시 변경 충돌을 재시도합니다. 클라이언트는 결과 수치를 직접 쓰지 않습니다.
- 같은 행동 요청 ID의 재처리는 180개 요청 이력 내에서 중복 결제를 방지합니다.
- 민감한 메시지는 응답 전에 참가 국가를 기준으로 필터링합니다. 방 코드만 가진 미참가자는 게임 상태를 읽지 못합니다.
- 서버의 HTTP 요청 시점에 밀린 시간을 정산합니다. 별도 상주 프로세스·cron이 필요하지 않습니다.
- 키나 Firebase 설정이 필요하지 않습니다. 기존 Firebase 버전과 데이터는 별도입니다.

## 실행 / 검증

Node.js 24 권장. 저장소의 고정 pnpm 의존성을 설치한 뒤:

```sh
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_living_skullbuster.sql
npm run dev
```

위 마이그레이션은 새 로컬 DB에 한 번 적용합니다. 이미 적용한 DB에 반복하지 마세요.

```sh
node --experimental-strip-types tests/game.test.mjs
node tests/server.test.mjs
node node_modules/typescript/bin/tsc --noEmit
```

서버 검사는 `npm run build` 후 실행하며, 격리된 Miniflare/실제 Worker 및 D1에서 네 세션의 동시 요청을 확인합니다.

## 배포

이 버전은 서버와 DB가 필요하므로 GitHub Pages만으로 실행할 수 없습니다. Sites에 배포할 때 `.openai/hosting.json`의 `d1: "DB"`에 따라 DB와 마이그레이션이 적용됩니다. Sites가 관리하는 Git 소스와 GitHub `multiplayer-v4/` 폴더에 같은 애플리케이션 소스를 보관합니다.

방 참가에는 호스팅 주소 자체의 접근 권한도 필요합니다. 본인 전용 게시 상태에서는 다른 사람의 접속이 제한됩니다. 친구들에게 공개하기 전에 링크 접근 범위를 설정해야 합니다.

## 검증 범위와 제한

규칙 검사와 Worker/D1 통합 검사로 4인 동시 참가·국가 선택·정책 선택, 중복 결제 방지, 비밀 메시지 격리, 지연 행동, 재접속, 10턴 정산, 최종 점수를 확인했습니다. 이 작업 환경에서는 브라우저 시각/클릭 QA를 수행할 수 없었습니다. 실제 4인 장시간 플레이에 따른 밸런스 조정은 아직 필요합니다.

공개 서비스 규모의 계정 체계, 광범위한 악성 트래픽 제한, 장기 방 정리 정책은 포함하지 않았습니다. 방 코드를 아는 사람은 시작 전 빈 자리에 참가할 수 있습니다. 교육용 소규모 플레이를 대상으로 합니다.
