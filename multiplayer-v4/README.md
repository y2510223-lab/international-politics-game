# 긴장의 시대 — 2~4인 국제정치 멀티플레이

공개 게임: https://era-of-tension-four-nations.jagongo.chatgpt.site

## 플레이

이름을 입력해 방을 만들고 6자리 코드나 초대 링크로 참가합니다. 2~4명이 서로 다른 국가를 고르고 모두 준비하면 방장이 시작합니다. 한 브라우저 프로필은 한 참가자입니다. 세션 쿠키가 유지되면 새로고침 후 복귀할 수 있습니다.

10턴을 동시에 진행하며 턴 시간은 60/90/120초 중 선택합니다. 연결이 끊겨도 시간은 흐릅니다. 턴 시작에 전체 화면 정책 카드 3개와 보류가 표시됩니다. 마우스·키보드 초점·터치로 가상 국민의 찬반 토론을 읽고 선택합니다. 정책은 24초 후 시행하며 비용은 선택 시 지불합니다. 명시적 보류에는 비용과 지지 손실이 없습니다. 미응답으로 턴이 끝나면 자동 보류하며 지지가 소폭 감소합니다.

## 행동과 예산

공개 성명·협정·원조·제재·비밀 전문·비공개 협력·병력 증강·최후통첩·전쟁·산업 투자·민생 지원·인프라 건설을 유지합니다.

- 행동의 턴당 사용 제한은 없습니다. 동일 행동이 완료되면 다시 실행할 수 있습니다.
- 최대 4개 국가 행동을 병행하며 정책 시행 대기열은 별도입니다.
- 행동 대기는 이전보다 길어졌습니다. 성명 12초, 협정 20초, 원조 28초, 제재 32초, 전문 5초, 비공개 협력 24초, 병력 증강 35초, 통첩 24초, 전쟁 55초, 산업 투자 35초, 민생 지원 26초, 건설 42초입니다.
- 진행 중인 행동은 다음 턴으로 이어집니다. 마지막 턴에는 게임 종료까지 완료 가능한 행동만 시작합니다. 늦게 채택한 정책은 최종 결산에서 시행합니다.
- 수입은 `0.055 + 경제/1200 + 인프라/2400 + 키레네 보정 0.015` G/초로 이전 기본 수입의 약 15~20%입니다. 예산을 주는 정책의 수입도 줄였습니다.
- 화면에는 비용 규모와 효과를 정성적으로 표시합니다. 현재 잔액·능력치·시간은 표시하지만 증감량은 소폭/상당히/크게 상승·하락으로 표현합니다.

## 분야별 협력과 사회 반응

협정과 비공개 협력은 무역·공급망, 보건·방역, 기술·디지털, 기후·재난, 교육·일자리 중 하나를 골라 제안합니다. 수락 국가도 예산을 분담합니다. 분야마다 효과가 다르며 이후 위기 피해를 완화할 준비도를 쌓습니다. 교육은 현재 실업도 완화합니다. 비공개 협력의 분야·반응·준비도는 제삼자에게 공개하지 않습니다.

공개 관계는 중립·우호·협력·긴장·충돌의 선으로 표시합니다. 우호 관계에서의 제재, 또는 전쟁·최후통첩은 상대와 그 우호국 시민의 불매 운동을 일으킵니다. 불매는 공격국 경제를 손상시키고 일정 기간 수입을 절반으로 낮추며 신문과 국민 반응에 남습니다. 우호국에 대한 원조는 시민 모금과 추가 지원으로 이어질 수 있습니다.

## 국민과 국가 신문

지도 인물 모형과 주기적인 말풍선을 제거했습니다. 선택 시 화면 테두리에서 가상 시민 반응이 즉시 나타나며, 심각한 사건에서는 최대 5개로 늘어납니다. 모든 인물과 발언은 창작이며 실제 뉴스 댓글이나 실제 개인의 발언으로 표시하지 않습니다.

정책별 이미지 12개와 찬성·반대·재반론을 제공합니다. 국가별 배경색, 지표 강조, 정성적 결과 알림을 유지합니다.

신문은 흑백·디지털·종이·평화저널로 구별됩니다. 신문 표지 형태의 버튼과 상시 신문 바로가기로 펼칩니다. 짧은 삽화 기사, 국가별 논조, 실제 다음 사건의 전조, 관계 변화와 급변 호외를 제공합니다. 정기판은 2턴마다 발행하고 기존 여론 평가를 유지합니다. 호외 자체는 지표를 바꾸지 않습니다.

## 세계 사건과 피해

세계 사건은 13종입니다. 해협 긴장, 무역 회복, 팬데믹, 평화 주간, 기후 재해, 인구 변화, 디지털 전환에 금융 위기·식량 공급 붕괴·정전·사이버 공격·대지진·난민 주거 위기를 추가했습니다. 동일 확률로 선택되고 반복될 수 있습니다. 특정 국가 추가 효과는 해당 국가가 실제 참가한 경우에만 적용됩니다.

팬데믹과 재해 등은 사망·실업 피해를 생성하며, 기반 시설·경제와 협력 준비도에 따라 완화됩니다. 전쟁도 인명·고용 피해를 발생시킵니다. 산업 투자·민생 지원·교육 협력은 재취업을 돕습니다. 신문은 발행 시점의 국내 누적 사망자, 현재 실업자, 참가국 전체 합계와 현재 사건의 누적 사망자를 정확한 인원으로 기록합니다. 이는 게임의 가상 집계이며 현실 통계가 아닙니다. 소폭/크게 표현의 예외는 이 피해 인원입니다.

팬데믹 최초 발생 경고는 세 차례 표시하며, 동작 줄이기 환경에서는 점멸하지 않습니다.

## 결과와 기술 구조

10턴 후 번영=(경제+인프라)/2, 민심=지지, 안보=군사, 외교=관계, 국가 목표=국가별 핵심 능력치의 평균으로 순위를 매깁니다. 동점은 공동 순위입니다.

React/Vinext, Worker API, D1 방 JSON 저장을 사용합니다. 서버가 시간과 비용을 판정하고 revision 조건부 갱신으로 동시 변경 덮어쓰기를 막습니다. 중복 요청 ID는 중복 지불을 방지합니다. 새 필드는 기존 방에 안전한 기본값을 적용하며 DB 스키마 변경은 없습니다. Firebase 기반 루트 게임은 별도로 보존합니다. 현재 앱은 GitHub multiplayer-v4/와 Sites 소스에 저장합니다.
